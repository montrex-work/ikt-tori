About the project

This project is about gamifying learning. We created an interactive web game to help students learn and practice in a more engaging and enjoyable way.

The project combines an educational website with supporting learning materials and a presentation.

Repository Structure
task/ – Contains the original documents and instructions provided by the teacher. These files serve as the source material and explain the requirements of the project.
documents/ – Contains the finished project deliverables, including the final PowerPoint presentation (.pptx) and Word document (.docx).
Root directory – Contains the HTML website and its supporting files, which make up the interactive learning game.
Website Hosting

The website is hosted using GitHub Pages, making it accessible online without requiring a local installation.
